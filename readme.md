Weather & Movie Search

A two-in-one web application built with html tailwind css and javascript. the live data are brought from public APIs. Has a nav bar to switch between both of the web application.
the following data are fetched by public APIs then are processed and rendered in a presentable maner. It also handles errors quite well.

Weather App:- Type in a city name to check that place's weather status. the Open-Meteo API has been used to build this page.

Movie search App:- used for looking up avaliable movies of a series and their description. the OMDb API has been used in making of the page.

Tech used:-
HTML5
Tailwind CSS
JavaScript
Git and GitHub

the project is also deployed via netlify. project link - https://weather-movies.netlify.app
